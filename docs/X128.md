# Generic x128 reference architecture

x128 is an experimental architecture defined by Generic OS. It is not an
existing standardized CPU target, so the first implementation is an executable
reference ISA and emulator rather than a pretend hardware port.

The reference machine has 16 general-purpose 128-bit registers, a 128-bit
program counter/address model, byte-addressable memory, wrapping arithmetic,
conditional branches, console output and a deterministic halt status.
Instructions are fixed at 20 bytes: opcode, three register fields and a
128-bit little-endian immediate.

The emulator currently implements 64 KiB of physical RAM. Architectural
addresses remain 128-bit; accessing an unimplemented address traps. This keeps
address width separate from the amount of RAM in a concrete machine.

Run the acceptance test with:

    bash scripts/x128.sh smoke

Build an encoded image with:

    bash scripts/x128.sh build

The bootstrap validates (2^128 - 1) + 1 == 0, conditional branching, byte
store/load and console output. Success requires the marker:

    GENERIC x128: READY

The next x128 work is a trap/interrupt model, privilege levels, MMU/page-table
format, atomics, timers, executable format and a compiler backend. Only after
those contracts are stable should the full Rust kernel be cross-compiled to
x128.
